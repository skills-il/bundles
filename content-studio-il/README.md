# Hebrew Content Studio Bundle

Making content in Hebrew is not making content in English with a different font. Right-to-left breaks slide layouts, mixed Hebrew and Latin text breaks line flow, subtitle burn-in mangles nikud, and generic tools quietly get all three wrong. This bundle is the production side of Hebrew content: the deck, the design system behind it, the article, the podcast clips, the scheduling, and the launch.

## Key facts

- **RTL is the actual problem**. The Presentation Generator exists because Hebrew decks need Hebrew fonts, right-aligned bullets, and bilingual text in a single document, which is where general-purpose slide tools fail.
- **Hebrew typography has known good pairings**. The Israeli UI Design System skill covers pairings such as Heebo with Inter and Rubik with Source Sans 3, gov.il design patterns, and Israeli formatting conventions (shekel sign, DD/MM/YYYY dates, 24-hour clock).
- **Podcast post-production is where Hebrew tools break hardest**. RTL show notes, nikud, and Hebrew subtitle burn-in are handled explicitly, because the generic tools (Kapwing, Maestra, Descript, Podsqueeze) mishandle them.
- **Distribution reaches 28+ channels**. Postiz schedules to X, LinkedIn, Instagram, Facebook, Threads, YouTube, TikTok, Telegram, Bluesky, Mastodon, Medium, Dev.to, WordPress and more from one place.
- **Israeli launch has its own map**: tech media (Geektime, Calcalist), VC demo days, holiday timing, 8200 alumni networks, and the Facebook and WhatsApp groups where early adopters actually are.
